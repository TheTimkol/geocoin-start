# Contributing

## Repository language

Write repository documentation, source comments, commit messages, issue and pull request text, release titles, and release notes in English. Keep user-facing application strings in the languages supported by the interface.

## Changes

- Keep the app focused on a simple, guided GeoCoin experience.
- Preserve links and attribution to the original GeoCoin project.
- Do not include wallet secrets, passwords, or private user data in commits, logs, screenshots, or release assets.
- When changing installer or release assets, update and verify the published SHA-256 checksums.
