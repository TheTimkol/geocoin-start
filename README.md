# GeoCoin-Start

Простой установщик и кошелёк GeoCoin для Windows 10/11 x64. Проект сделан TheTimkol, чтобы обычному пользователю было проще запустить оригинальную ноду и пользоваться основными возможностями монеты.

## Скачать

[Скачать GeoCoin-Start-Setup.exe](https://github.com/TheTimkol/geocoin-start/releases/latest/download/GeoCoin-Start-Setup.exe)

[Контрольная сумма установщика](https://github.com/TheTimkol/geocoin-start/releases/latest/download/SHA256SUMS.txt)

Запустите файл и нажмите «Установить». Нужен интернет: установщик скачивает официальный пакет GeoCoin v0.1.3 с релиза автора, сверяет контрольную сумму SHA-256 и устанавливает файлы в папку пользователя. Права администратора и предварительная установка .NET не нужны.

## Что внутри

- Обзор: состояние ноды, синхронизация и баланс.
- Майнинг на процессоре: выбор количества потоков и подтверждение запуска.
- Отправка монет с расчётом комиссии и подтверждением перевода.
- Получение монет: создание адреса и копирование в буфер обмена.
- Создание кошелька с паролем и зашифрованная резервная копия.

Кошелёк и данные сети хранятся на этом компьютере в `%LOCALAPPDATA%`. Установщик не запускает майнинг автоматически. Эта версия показывает CPU-майнинг; настройки GPU в простой интерфейс не добавлены.

## Ссылки и авторство

- Оригинальный проект и автор: [NoemaCrypt / GeoCoin](https://github.com/NoemaCrypt/GeoCoin)
- Официальный релиз GeoCoin v0.1.3: [страница релиза](https://github.com/NoemaCrypt/GeoCoin/releases/tag/v0.1.3)

GeoCoin-Start не является официальным приложением NoemaCrypt. Нода, кошелёк и майнер скачиваются без изменений из официального релиза GeoCoin; приложение добавляет упрощённый интерфейс и шаг установки.

## Сборка

Нужен .NET 10 SDK для Windows x64. Из корня репозитория выполните:

```powershell
powershell -ExecutionPolicy Bypass -File installer\GeoCoinStart\InstallerBuild.ps1
```

Установщик не подписан сертификатом издателя, поэтому Windows может показать предупреждение о неизвестном издателе.
